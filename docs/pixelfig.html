把中文内容
画成像素图

输出真实 PNG，不走 SVG。

中文排版开箱可用。

npx skills@latest add dongliang/skills --skill pixelfig

字体要单独下（约 12MB）：sh scripts/install-fonts.sh

效果

它能做什么

  • 把一段文字排成一张图：标题条、面板、色条、图标、箭头
  • 中文用像素字体渲染，小字不糊
  • 在一张约 290px 宽的逻辑画布上作画，输出时整数倍放大
  • 自动按内容累加高度，不用预设画布尺寸

用法

# 装完字体后，在 Python 里直接调
import sys; sys.path.insert(0, "scripts")
from pixelfig import *

c = Canvas(290, 200)
c.bar(10, 8, 270, 18, PURPLE, label="标题")
c.panel(10, 30, 270, 60, accent=CYAN, fill=CYAN_L)
c.text(22, 40, "正文", 12, INK)
c.save("out.png", scale=3)

依赖

用途来源
图像绘制Pillow（Python 3）
中文像素字Fusion Pixel Font · Cubic 11（均为 OFL-1.1）

已知限制

  • 中文像素字最小 12px，再小笔画会断
  • 放大倍率只用整数，非整数倍会让像素块大小不匀
  • 只在能读文件的 agent 里可用，纯聊天界面用不了
