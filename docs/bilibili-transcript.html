把 B 站视频
变成能读的文字

字幕、文字稿、AI 总结，一条命令拿走。

技能自带脚本 · 零 npm 依赖 · 扫码登录

npx skills@latest add dongliang/skills --skill bilibili-transcript

装完即用，脚本随技能一起来，不需要再装别的东西。

跑起来是这样

bilibili-transcript
$ node src/cli.mjs "https://b23.tv/xxxxx" --plain
# 装上它，AI 编程通过率从 6.7% 涨到 96.7%
UP: 某 UP 主 | 时长 1159s

$ node src/cli.mjs BV1xx411c7mD --plain -o out.txt
已写入 out.txt（5618 字符）

它能做什么

  • 把任意 B 站视频的字幕扒成文字，带不带时间戳都行
  • 拿 B 站官方的 AI 视频总结，带章节和时间点
  • BV 号、av 号、完整链接、b23.tv 短链都认
  • 合集视频可以只取某一集（分P）
  • 给 agent 用的 --json 结构化输出

三步开始

# 1. 登一次，以后不用再登（扫码）
node src/cli.mjs login

# 2. 提取文字稿
node src/cli.mjs BV1xx411c7mD --plain

# 3. 长视频写进文件再看
node src/cli.mjs "https://b23.tv/xxxxx" --plain -o out.txt

出问题了先跑 node src/cli.mjs doctor，它分得清是接口变了、凭据过期了还是环境有问题。

命令一览

选项作用
--plain只出连续文字，不带时间戳
--json结构化输出，给程序用
-p N取第 N 个分P
--list只列字幕轨，不下正文
--summary附带 B 站 AI 总结
-o FILE写入文件

已知限制

  • 字幕接口强制登录，必须先扫码一次
  • 字幕是 AI 自动生成的，专有名词常出错，别直接信
  • 纯音乐、MV、CG 类视频通常没有字幕轨
