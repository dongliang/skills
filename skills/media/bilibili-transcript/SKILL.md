# B 站视频文字稿

命令 `bili`（全名 `bili-transcript`）。**没装就直接用 npx，不用问用户。**

```sh
bili <BV号|av号|URL> --plain
npx -y bili-transcript@latest <目标> --plain    # 没装时用这条
```

**先跑 `bili --version`**：不是 `1.1.x` 就用 npx 拉最新——本文件的行为描述跟版本绑定，
版本不对会照着过时的坑去「修」已经修好的地方。

| 选项 | 作用 |
|---|---|
| `--plain` | 连续文字，无时间戳。**给 AI 读、给人读都用这个** |
| `-o FILE` | 写文件。长视频必须用，别把几千字刷进对话 |
| `--json` | 结构化输出（含 `lines[]` / `subtitles[]` / `summary`），给程序解析 |
| `-p N` | 取第 N 个分P（合集视频必用） |
| `--list` | 只列出字幕轨 |
| `--summary` | 附带 B 站 AI 总结（带章节时间点） |

- 出问题先跑 `bili doctor`——它能分清是**凭据过期**、**接口变了**还是**环境有问题**。
- 要登录时 `bili login`。TTY 下会问：`1) 打开浏览器登录` / `2) 二维码扫码登录`。
  浏览器已登录 B 站时**不用扫码**，凭据会自动从本机浏览器读。
- **任何时候不要打印 `SESSDATA` 的值**，只说「有没有」。

## 输出时注意

- **字幕是 AI 生成的，专有名词会错。** 实测：`CAMM` 写成 "cam"、`信号线阻值` 写成
  "信号线组织"、`焊球` 写成 "气球"。别直接引用，去核实物件丝印或官方资料——硬件类视频尤其如此。
- 没有字幕轨（纯音乐/MV/CG 常见）就直说没有，别硬编。
- 长视频文字稿写文件，别整段刷进对话。

## 边界

- 用户说「不要登录」「别用我账号」→ 只剩「下音频 + 外部 ASR」，如实说明，别假装能本地跑。
- 用户说「别读我的浏览器」→ 尊重，只走环境变量和 `auth.json`。

内部实现、接口坑、cookie 解密细节见仓库 README。
